# Dhafin Dilry — GitHub Pages

Isi paket ini sudah disiapkan untuk GitHub Pages.

## Struktur
- `index.html` — halaman utama website
- `assets/` — gambar/foto yang digunakan website

## Cara upload
Ekstrak ZIP ini terlebih dahulu. Upload `index.html` dan folder `assets` ke repository GitHub. Pastikan `index.html` berada di root repository.
